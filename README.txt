BLACKJACK STRATEGY TRAINER — PRIVATE IPHONE PWA

1. Create a free GitHub account (if needed).
2. Create a new repository, e.g. blackjack-trainer.
3. Upload the files from this ZIP to the repository root (not the enclosing folder).
4. Settings > Pages > Deploy from a branch > main / root > Save.
5. Wait for the Pages URL, then open it in Safari on iPhone.
6. Share > Add to Home Screen > Add.
7. Open once while online to cache the app for offline use.

IMPORTANT: GitHub Pages websites are publicly accessible by URL, even if you are the only person using the game. Do not store private data in the repository. Your accuracy stats are stored locally on the iPhone.
